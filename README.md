# Shreedhar Devfolio

Personal portfolio for Shreedhar K B, built as a simple terminal-inspired static site.

Live preview: https://shreedhar-devfolio.vercel.app/

All content lives in `data.js` — edit that file and nothing else.

## Sections

- Profile
- Projects
- Skills
- Education
- Leadership
- Contact

## Local Preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:4173/
```
